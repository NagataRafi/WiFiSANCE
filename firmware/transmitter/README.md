# Firmware Transmitter

Folder ini diperuntukkan untuk firmware ESP32 transmitter.

## Fokus awal

- menyiapkan mode TX Wi-Fi;
- memastikan komunikasi basic ke receiver dapat diuji;
- menyimpan konfigurasi yang terbukti saat pengujian CSI dilakukan.

## Status

Belum ada firmware aktif yang dibuat. Struktur folder ini disiapkan sesuai PRD untuk pengembangan modul TX di tahap berikutnya.
