# Firmware Receiver

Folder ini diperuntukkan untuk firmware ESP32 receiver dan modul akuisisi CSI.

## Fokus awal

- menerima paket dari TX;
- mengakses data CSI yang dihasilkan receiver;
- menyimpan log CSI bersama metadata sesi.

## Status

Belum ada firmware aktif yang dibuat. Folder ini disiapkan sebagai fondasi untuk pengujian CSI proof of concept.
