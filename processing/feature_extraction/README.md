# Feature Extraction Module

Folder ini berisi modul untuk membangun representasi fitur dari CSI yang siap dimasukkan ke model ML.

## Fokus awal

- mengekstraksi karakteristik sinyal yang relevan;
- menyimpan fitur hasil ekstraksi agar dapat dipakai ulang;
- memisahkan output fitur dari data raw dan data preprocessing.

## Status

Belum ada feature engineering yang dipilih. Fitur final akan ditentukan dengan eksperimen dan evaluasi empiris.
