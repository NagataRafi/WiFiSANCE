# Preprocessing Module

Folder ini berisi modul untuk validasi, cleaning, filtering, dan normalisasi data CSI.

## Fokus awal

- menghapus artefak atau noise yang jelas;
- menjaga data mentah tetap terpisah;
- menyiapkan data yang siap diproses lebih lanjut.

## Status

Belum ada pipeline preprocessing yang diimplementasikan. Parameter dan metodologi akan ditentukan setelah prototyping CSI.
